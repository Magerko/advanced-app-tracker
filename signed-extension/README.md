# Signed Firefox extension

`advanced-app-tracker.xpi` here is the extension from `../extension`, signed
by Mozilla, so it can be installed permanently in normal Firefox.

Install it from the app (tab **Браузер** → **Установить расширение в Firefox**)
or drag the file into a Firefox window.

To make a new file after changing the extension, see
[docs/browser-tracking.md](../docs/browser-tracking.md#for-developers).
